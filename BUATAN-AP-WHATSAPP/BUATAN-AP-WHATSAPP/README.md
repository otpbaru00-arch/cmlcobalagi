# BUATAN AP — WhatsApp Embedded Signup Demo

Ini adalah prototipe UI onboarding yang meniru alur umum Embedded Signup:
1. Pengantar koneksi
2. Pemilihan aset bisnis
3. Pembuatan akun WhatsApp Business (simulasi)
4. Ringkasan koneksi (simulasi)

## Menjalankan
Cukup buka `index.html` di browser.

## Catatan keamanan
- Proyek ini TIDAK meminta atau menyimpan username/password Facebook/Meta.
- ID WABA/Phone Number pada halaman hasil adalah ID demo acak.
- Untuk koneksi WhatsApp nyata, gunakan Meta Embedded Signup + WhatsApp Cloud API resmi.
- Simpan App Secret dan access token di backend/server, jangan di frontend.

## Struktur
- `index.html`
- `style.css`
- `app.js`
